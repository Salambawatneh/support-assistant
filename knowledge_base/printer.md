# Printer problems | مشاكل الطابعة

If a printer is not responding, check that it is powered on and connected to the network, then clear the print queue and try again. For paper jams, open the rear tray, remove the paper gently, and restart the printer.

To add a network printer, go to Settings, Printers, Add printer, and select the printer by its floor label.
